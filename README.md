# 🌸 Iris Flower Clustering using K-Means

## 📌 Project Overview

This project applies **K-Means Clustering** to the Iris Flower dataset.

The objective is to group Iris flowers into **3 clusters** based on their flower measurements and compare the predicted clusters with the actual flower species.

This project demonstrates the basic concepts of **Unsupervised Machine Learning** and **Data Visualization**.

---

## 🎯 Objectives

* Apply K-Means Clustering with `k = 3`
* Use flower measurements for clustering
* Visualize the generated clusters
* Compare predicted clusters with actual species
* Calculate the Adjusted Rand Index (ARI)

---

## 📊 Dataset

The project uses the **Iris Flower Dataset** downloaded from Kaggle.

The dataset contains measurements of Iris flowers:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

The dataset also contains the actual species labels:

* Iris-setosa
* Iris-versicolor
* Iris-virginica

The `Species` column is used only for comparison after clustering because K-Means is an unsupervised learning algorithm.

---

## 🧠 Algorithm Used

### K-Means Clustering

K-Means is an **unsupervised machine learning algorithm** that divides data into a specified number of groups called clusters.

For this project:

```text
Number of clusters (k) = 3
```

The algorithm groups flowers according to similarities in their measurements.

## 📈 Visualization

The project creates a scatter plot using:

* X-axis → Petal Length
* Y-axis → Petal Width

Different colors represent the clusters generated by K-Means.

---

## 📋 Cluster Comparison

The project uses a cross-tabulation to compare:

```text
Actual Species
       vs
Predicted Cluster
```

Because K-Means assigns cluster numbers automatically, Cluster `0`, `1`, and `2` do not necessarily correspond directly to a particular species.

---

## 📊 Evaluation

The **Adjusted Rand Index (ARI)** is used to compare the clustering results with the actual species labels.

ARI measures the similarity between the predicted clustering and the true grouping while accounting for the fact that cluster numbers themselves are arbitrary.
